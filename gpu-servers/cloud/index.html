FAQ

常见问题

Как оформить заказ?

Выберите конфигурацию в каталоге → Add to Cart → войдите в B2B-кабинет (email + компания) → Generate Invoice. Счёт формируется сразу; оплата по реквизитам в RUB / BYN / CNY / USDT.

Which currencies are supported?

RUB, BYN, CNY, and USDT. Сумма в счёте фиксируется в выбранной валюте на момент генерации invoice.

Where are instances physically hosted?

Hong Kong and mainland China (Greater Bay Area). Provider facilities meet ISO/IEC 27001 and cloud security baselines.

When does provisioning start?

После поступления оплаты по счёту — автоматический provisioning в выбранном регионе. Статус instance доступен в B2B-кабинете.
